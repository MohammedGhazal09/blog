| Reader activation → external YouTube nocookie origin | The first third-party request occurs only after explicit native-button intent. |
| Focused trigger → dynamically inserted cross-origin iframe | DOM replacement must retain a named focus target and allow navigation onward without a page-level trap. |

| T2-03 | Tampering / Elevation | Player click handler | mitigate | Hardcode nocookie origin, accept no full URL, use one-shot listener plus existing-iframe guard, and assert one iframe/request. |
