## Trust Boundaries

| Boundary | Description |
|---|---|
| Repository article/registry input → build validation | Git-reviewed author input can contain malformed or deceptive facts that must fail closed. |
| Raw Markdown/MDX source → Astro compilation | Restricted source syntax must be rejected before compiler execution. |
| Validated complete collection → public/preview query | Production must never receive draft records or path collisions. |
| npm registry/lockfile → local and CI build | Clean installation must reproduce the exact audited graph under the exact runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01 | Spoofing | Arabic section/article slugs | mitigate | Native tests cover NFC, Arabic grammar, every separator/control/bidi class, and exact reject behavior in the shared helper. |
| T-02 | Spoofing / Tampering | Complete article path | mitigate | Native collision tests require complete path plus both owners before draft filtering. |
| T-03 | Tampering / Information Disclosure / Elevation | MDX import/export | mitigate | Native policy tests and config-load preflight reject ESM before Astro compilation; no secrets or `.env` access exists. |
| T-04 | Tampering | Raw script/iframe or unknown JSX | mitigate | Table-driven cases cover case/spacing variants and central allowlist enforcement. |
| T-05 | Denial of Service | Malformed content | mitigate | Every invalid fact is isolated in fast tests and production failures remain actionable; invalid files never poison the normal content directory. |
| T-06 | Information Disclosure | Draft query and routes | mitigate | Tests and build output inspection prove public filtering precedes route generation and preview fails closed outside development. |
| T-01-SC | Tampering | npm packages and lockfile | mitigate | Exact runtime check plus `npm ci` reproduces the research-approved lock; no additional package is installed. |

These controls apply to trusted Git-reviewed authoring and must not be represented as a sandbox for hostile uploads.
