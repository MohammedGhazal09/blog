Purpose: Establish the architectural contract that every later article, route, metadata record, and section consumer will reuse without adding a backend or alternate content model.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Repository article/registry input → build validation | Git-reviewed author input is trusted operationally but can contain accidental malformed or unsafe facts. |
| Raw Markdown/MDX source → Astro compilation | MDX syntax can execute imports or bypass the approved component surface unless preflighted before compilation. |
| Validated complete collection → public/preview query | Draft filtering or collision checking in the wrong order can publish a hidden route. |
| npm registry/lockfile → local and CI build | Package identity/version drift can change the privileged build toolchain. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01 | Spoofing | Arabic section/article slugs | mitigate | `assertCanonicalArabicSlug` requires already-NFC Arabic/digit grammar and rejects control/format/bidi characters before path creation. |
| T-02 | Spoofing / Tampering | Complete article path | mitigate | `assertUniqueArticlePaths` compares every validated complete path before draft filtering and reports both source owners. |
| T-03 | Tampering / Information Disclosure / Elevation | MDX import/export | mitigate | Plan 02 preflights raw article source before Astro compilation and forbids article-authored ESM; no secrets or `.env` reads are introduced. |
| T-04 | Tampering | Raw script/iframe or unknown JSX | mitigate | Plan 02 rejects script/iframe tags and components outside the one central allowlist before compilation. |
| T-05 | Denial of Service | Malformed frontmatter/registry data | mitigate | One schema plus pure semantic rules fails closed with source, field/path, and rule; invalid cases live only in tests. |
| T-06 | Information Disclosure | Draft query and route enumeration | mitigate | `getPublicArticles` filters before `getStaticPaths`; `getPreviewArticles` requires explicit development mode. |
| T-01-SC | Tampering | npm packages and lockfile | mitigate | Install only the four research-audited approved exact packages and commit `package-lock.json`; no assumed, suspicious, or slop packages are permitted. |

The MDX preflight is a policy guard for trusted Git-reviewed files, not a hostile-input sanitizer or sandbox.
</threat_model>
