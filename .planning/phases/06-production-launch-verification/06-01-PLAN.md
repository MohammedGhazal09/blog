## Trust Boundaries

| Boundary                             | Description                                                                                                                            |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| operator process value → CLI         | Untrusted `SITE_ORIGIN` can otherwise become an SSRF, credential, or local-network target.                                             |
| production origin → static parser    | Redirects, oversized bodies, malformed XML/HTML, entity declarations, duplicate URLs, and hostile links cross from the public network. |
| controlled fixture → evidence report | Synthetic success can be confused with a final-origin observation if authority is caller-controlled.                                   |
| runner → filesystem                  | Generated evidence must stay in one ignored fixed root and exclude sensitive response/request data.                                    |
